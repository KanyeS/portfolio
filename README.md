## About the Site

This portfolio website is built using **React** and **Vite** hosted via **Netlify** with **Google Analytics** and **Cloudlfare** to gain experience with a live site and is designed to showcase my personal projects and skills. It includes interactive elements, responsive design, and smooth animations to ensure a user-friendly experience across all devices. You can view details about each of my projects and the skills I've used in their development.

## Installation and Setup

To run this project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/KanyeS/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open your browser and navigate to `http://localhost:3000` to view the site.
